# Contributing

Submit an issue with the original creator URL, explicit MiniMax H3 Image attribution, the exact published prompt and output. Include every required reference input in order. Do not reverse-engineer a prompt and present it as the creator's original.

Examples without a published prompt belong in `data/showcases.json`. Count an album or comparison as one example. Keep reference inputs separate from results. Identify every model in a cross-model comparison.

Deliver image assets as WebP on BeatAPI storage, retain original source URLs and SHA-256 hashes, and preserve creator attribution. Record known rights accurately; public visibility is not a separate license grant.

Website and repository use the same JSON records. Update both READMEs and the relevant use-case page when adding an example.
